# TOP MOVIES
Desenvolvimento de site de busca de filmes e séries. O site oferece recursos para busca dos melhores e mais populares filmes, além de um design atraente e intuitivo, sendo capaz de realizar filtros por plataforma de streaming, gênero, etc. Para realizar essas buscas, foi consumida a API fornecida por The Movie Database (TMDB).
